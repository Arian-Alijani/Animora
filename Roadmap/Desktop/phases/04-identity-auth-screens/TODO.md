Six decisions this list encodes, so the implementing sessions do not re-litigate them:

- **The login screen is a rail-visible route in Stage A.** No pre-shell authentication window exists
  (the shell is always shown, phase 02), and PHASE.md requires the login screen to be navigable from
  the shell. It is registered like any other route and carries the `TODO(P2)` marker recording that
  real authentication moves it ahead of the shell.
- **The permission-claim catalog is a module-owned transcription**, taken verbatim from
  10-security-and-access-control's grouped table, with `PlatformAdmin` excluded (platform-level, not
  tenant RBAC). It is not invented and not duplicated into `Animora.Contracts`: the server's seed
  data becomes its source in P2 (`TODO(P2)`), per SEC-09 and INV-18.
- **Read and write seams are split per aggregate even in Stage A** (`I…ReadStore` / `I…WriteStore`),
  because Stage C binds them to different technologies (Dapper reads / EF Core writes, DT-05) and a
  merged interface would have to be torn apart then.
- **Field-level rules for staff, roles and credentials are this phase's recorded default** — the
  corpus fixes the RBAC model but no field formats (AG-02), so the values chosen in items 1-3 follow
  phase 03 item 9's precedent: documented, reviewable, and changeable without touching any other
  layer.
- **Sign-in reaches `ICurrentUserState` through a Mediator notification**, handled in
  `App/AppState`. A module may not reference the composition root (AT-09), and cross-boundary work
  goes through `Mediator` (DT-01) — this is what finally resolves `CurrentUserState`'s `TODO(P1-04)`.
- **Subordinate staff usernames are namespaced under the owner-admin's username** (SEC-17, added to
  `10-security-and-access-control.md` once the product owner specified it): `{ownerUsername}-{suffix}`,
  e.g. `petshop` / `petshop-drahmadi`. `StaffValidator`'s format rule already permits the hyphen, so
  only the lookup-dependent part is new — one read method (item 11) and one handler check (item 22),
  the same split SEC-09's catalog-membership check already uses.
