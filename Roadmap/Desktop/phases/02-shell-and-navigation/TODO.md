composition root (AT-09) while it must still register its own routes (DT-09): the module-facing
navigation and app-state **abstractions** live in the leaf `Animora.Desktop.UI` project, their
**implementations** in `Animora.Desktop.App`; and the phase's one example screen lives in
`Animora.Desktop.Modules.Reporting` (the module that will own the real dashboard in phase 10) rather
than in the shell project.
