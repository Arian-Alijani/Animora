Three decisions this list encodes, so the implementing sessions do not re-litigate them:

- **The UTC clock is `System.TimeProvider`, not a new `IClock`.** Phase 01/02 already inject
  `TimeProvider` (`JalaliDateFormatter`, `InMemoryHomeSummaryReadStore`, `FixedTimeProvider`); a
  second abstraction for the same concern is a parallel implementation (AG-14). This phase adds only
  the UTC-typed extension surface CONV-04/06 needs on top of it.
- **Shared validators bind to input *interfaces*, not to copied input DTOs.** A desktop command (or
  a backend request) implements `IOwnerInput` and is validated directly, so one shape is authored
  once (CONV-18, INV-02) and `SharedKernel` still references nothing (SH-01).
- **`Animora.Contracts` stays a seed, not a catalog.** One lifecycle enum and the two DTOs the first
  consuming phase (05) binds to, shaped so the P2 OpenAPI swap is additive (CONV-19/20, SH-04).
